PROJECT NAME:
Cloud-Based Automated Video Processing and Auto-Posting System

BRIEF IDEA ABOUT YOUR PROJECT (2 lines):
Line 1: A cloud-based platform that automatically takes long YouTube videos, extracts the best moments, and renders short reels in parallel using AWS Lambda.
Line 2: All media assets and B-rolls are managed in cloud storage (S3), and the final reels are automatically scheduled and posted to Instagram using cloud triggers.

TECHNOLOGIES USED:
- Google Cloud Run: Hosts the main backend API on the cloud.
- AWS Lambda: Renders video clips fast using distributed serverless computing (Remotion).
- Amazon S3 / Cloud Storage: Stores raw videos, B-roll clips, and final rendered reels.
- Google Cloud Scheduler: Automatically schedules and publishes the reels to Instagram.
- Other Tools: Python (FastAPI), Remotion (React), Docker.
